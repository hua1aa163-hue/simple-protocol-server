# 简易报文 TCP 服务器

这是从 AutoCrosstalk 中独立出来的 .NET 8 WinForms 应用。程序启动后自动监听 `127.0.0.1:9527`，另一端应作为 TCP 客户端连接；同时包含独立的扩展投影切图/定时投图窗口。

## 使用方法

1. 在“命令类型”中选择需要的命令。
2. 切换配方、保存配方和获取焦距时，在参数框输入配方名或 VID。
3. “发送报文（可编辑）”会先生成选中命令的报文，也可手工修改。每次只填写一条以 `&|` 开始、以 `|@` 结束的报文。
4. 点击“发送一次”，将发送当前编辑框中的报文。
5. 点击“加入循环列表”可以依次添加多条不同报文；可删除、清空，或双击列表项回填到编辑框。
6. 在循环列表中设置“行间隔(秒)”，并在发送区域设置“循环(分)”：同一轮内相邻报文按行间隔发送，发送末行后按循环间隔等待，再从第一行开始下一轮。
7. 点击主界面的“扩展投影切图”，选择图片目录、投影模式和第二屏图片效果。图片效果支持原图、横向显示、横向翻转（左右镜像）、上下翻转（垂直镜像）和左右及上下翻转；默认使用原图。预览、手动投图、定时投图和串扰测试均使用当前效果，不会旋转显示器本身。可立即应用投影模式/图片效果、手动切换下一张，或按秒设置间隔后开始定时投图。
8. 投影窗口为独立的非模态窗口，打开后仍可操作主界面。单击图片列表中的一行后，可点击“投放选中图片”立即投放该图片。
9. 点击“串扰测试”后，程序以列表当前选中的图片为起点，先投放该图片，然后循环执行：发送主界面当前报文启动设备测试 → 等待最终完成返回 → 标记该图片测试完成 → 等待 1 秒 → 投放下一张 → 再次发送。列表会在末尾绕回开头，确保文件夹内每张图片恰好测试一次后自动结束。测量命令的 `Run` 只是中间应答，会继续等待最终 `OK`；发送失败、返回 `NG`、连接断开、等待超时或投图失败时均立即停止，不再继续投图。普通命令返回超时为 10 秒，测量命令为 600 秒；运行期间可点击“停止串扰测试”。

投影窗口支持 PNG、BMP、JPG、JPEG。为提高 Windows 壁纸接口兼容性，非 BMP 图片会自动转换到系统临时缓存；勾选“停止/关闭后恢复桌面”后会在停止定时投图或关闭窗口时恢复原桌面图片。

客户端断开或停止监听时，定时发送会自动停止。同一时间只能有一个程序监听 `9527` 端口。

## 新手源码阅读顺序

1. `Program.cs`：程序入口，了解 WinForms 如何启动主窗体。
2. `Protocol/CommandType.cs` 和 `Protocol/SimpleMessageProtocol.cs`：了解命令枚举、参数校验和报文字符串如何生成。
3. `Networking/TcpMessageServer.cs`：了解监听、发送、接收以及 TCP 拆包/粘包处理。
4. `MainForm.cs`：了解界面如何调用协议层和网络层，以及循环列表的双间隔发送逻辑。
5. `Protocol/CommandResponseMatcher.cs`：了解串扰测试如何区分 `Run`、最终 `OK`、`NG` 和无关返回。
6. `ProjectionForm.cs`：了解图片扫描、手动/定时投图和整文件夹串扰测试循环。
7. `Projection/DesktopDisplayService.cs`：最后再看 Windows API、投影模式切换和 BMP 缓存。
8. `*.Designer.cs`：这些是设计器生成的控件布局代码，理解控件名称和事件绑定即可，不建议逐行阅读坐标。
9. `SimpleProtocolServer.SmokeTests/Program.cs`：通过测试用例回顾各模块的预期行为。

## 设计器编辑

在 Visual Studio 中可分别打开 `MainForm.cs` 和 `ProjectionForm.cs` 的设计器。界面控件分别定义在对应的 `.Designer.cs` 文件中。

## 编译

```powershell
dotnet build SimpleProtocolServer\SimpleProtocolServer.csproj -c Release
```
