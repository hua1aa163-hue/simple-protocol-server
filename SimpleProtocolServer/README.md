# 简易报文 TCP 服务器

这是从 AutoCrosstalk 中独立出来的 .NET 8 WinForms 应用。程序启动后自动监听 `127.0.0.1:9527`，另一端应作为 TCP 客户端连接；同时包含独立的扩展投影切图/定时投图窗口。

## 使用方法

1. 在“命令类型”中选择需要的命令。
2. 切换配方、保存配方和获取焦距时，在参数框输入配方名或 VID。
3. “发送报文（可编辑）”会先生成选中命令的报文，也可手工修改。每次只填写一条以 `&|` 开始、以 `|@` 结束的报文。
4. 点击“发送一次”，将发送当前编辑框中的报文。
5. 点击“加入循环列表”可以依次添加多条不同报文；可删除、清空，或双击列表项回填到编辑框。
6. 在循环列表中设置“行间隔(秒)”，并在发送区域设置“循环(分)”：同一轮内相邻报文按行间隔发送，发送末行后按循环间隔等待，再从第一行开始下一轮。
7. 点击主界面的“扩展投影切图”，选择图片目录、投影模式和第二屏图片效果。图片效果支持原图、横向显示、横向翻转（左右镜像）、上下翻转（垂直镜像）和左右及上下翻转；默认使用原图。预览、手动投图、定时投图和串扰测试均使用当前效果。
8. 点击投图后，程序在第一个非主屏上打开无边框、置顶、黑底的全屏图片窗口，并严格按 1:1 像素显示：一个源图片像素对应一个第二屏物理像素，不使用 Zoom、插值、放大或缩小。小图黑底居中；大图居中并裁切超出屏幕的部分，绝不压缩。程序不会修改 Windows 桌面壁纸，也不会覆盖主屏。未检测到第二屏时会提示先连接并启用扩展屏幕。
9. 点击“串扰测试”后，程序以列表当前选中的图片为起点，先投放该图片，然后循环执行：发送主界面当前报文启动设备测试 → 等待最终完成返回 → 标记该图片测试完成 → 等待 1 秒 → 投放下一张 → 再次发送。列表会在末尾绕回开头，确保文件夹内每张图片恰好测试一次后自动结束。测量命令的 `Run` 只是中间应答，会继续等待最终 `OK`；发送失败、返回 `NG`、连接断开、等待超时或投图失败时均立即停止，不再继续投图。普通命令返回超时为 10 秒，测量命令为 600 秒；运行期间可点击“停止串扰测试”。

投影窗口支持 PNG、BMP、JPG、JPEG。图片按嵌入色彩配置读取，只加载到内存中的第二屏全屏窗口，不修改原文件、不改变桌面壁纸。应用启用 Per-Monitor-V2 DPI 感知，并通过 `DrawImageUnscaled` 原尺寸绘制。勾选“停止定时投图时关闭第二屏”后，停止普通定时投图会关闭全屏窗口；关闭投影控制窗口时始终关闭第二屏窗口。

客户端断开或停止监听时，定时发送会自动停止。同一时间只能有一个程序监听 `9527` 端口。

## 串扰数据自动处理

投影窗口下方可以选择原始数据目录和结果输出目录。原始目录首次默认是 `D:\Program Files\GYTech\Setup_MRTest\ExportFile`。开始测试前，程序会记录该目录下已有的一级文件夹；全部图片成功后，再按本轮测试开始时间、每次完成时间和测试次数匹配新增导出文件夹，不会把历史测试混入本批结果。

图片总数必须是大于等于 3 的奇数。前后两组图片数量相同，图片列表最后一张固定为本底并最后测试；其余图片仍可从当前选中项开始循环。每个匹配文件夹按名称读取第一个 XLSX 的 `Brightness` 工作表 C 列，执行用户 MATLAB 程序的 612 行、19×32、3% 异常阈值和边框规则。

每批结果新建一个独立目录，其中包含完整“原始数据”副本、测试与原始文件对应表、合并原始矩阵 Excel、串扰结果 Excel（Sheet1 为逐点结果，Sheet2 为 Max/Min/Mean）和 1500×900、300 DPI 热力图 PNG。

主界面的命令、参数、可编辑报文、循环列表和两个间隔，以及投影窗口的所有目录、下拉选项、投图间隔和复选框，都会在正常关闭时保存到当前 Windows 用户的本地配置目录；下一次打开自动恢复。首次运行仍默认选择“六、单次手动测试”。

## 新手源码阅读顺序

1. `Program.cs`：程序入口，了解 WinForms 如何启动主窗体。
2. `Protocol/CommandType.cs` 和 `Protocol/SimpleMessageProtocol.cs`：了解命令枚举、参数校验和报文字符串如何生成。
3. `Networking/TcpMessageServer.cs`：了解监听、发送、接收以及 TCP 拆包/粘包处理。
4. `MainForm.cs`：了解界面如何调用协议层和网络层，以及循环列表的双间隔发送逻辑。
5. `Protocol/CommandResponseMatcher.cs`：了解串扰测试如何区分 `Run`、最终 `OK`、`NG` 和无关返回。
6. `ProjectionForm.cs`：了解图片扫描、手动/定时投图和整文件夹串扰测试循环。
7. `DataProcessing/CrosstalkDataProcessor.cs`：了解 MATLAB 公式、时间/次数匹配、原始数据归档和结果输出。
8. `DataProcessing/SimpleXlsx.cs`：了解如何读取 Brightness C 列及写入结果工作簿。
9. `Settings/UserPreferences.cs`：了解上次界面值如何保存和恢复。
10. `SecondScreenProjectionForm.cs` 和 `Projection/PixelPerfectImageControl.cs`：了解如何寻找非主屏并严格按 1:1 像素显示图片。
11. `Projection/DesktopDisplayService.cs`：最后再看 Windows API 和投影模式切换。
12. `*.Designer.cs`：这些是设计器生成的控件布局代码，理解控件名称和事件绑定即可，不建议逐行阅读坐标。
13. `SimpleProtocolServer.SmokeTests/Program.cs`：通过测试用例回顾各模块的预期行为。

## 设计器编辑

在 Visual Studio 中可分别打开 `MainForm.cs`、`ProjectionForm.cs` 和 `SecondScreenProjectionForm.cs` 的设计器。界面控件分别定义在对应的 `.Designer.cs` 文件中。

## 编译

```powershell
dotnet build SimpleProtocolServer\SimpleProtocolServer.csproj -c Release
```
